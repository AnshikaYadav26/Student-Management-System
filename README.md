# Student Management System

A Java-based, menu-driven Student Management System designed for efficient student record management. The system allows users to add, view, search, sort, delete, and restore student records while demonstrating the practical application of Data Structures and Algorithms.

## Features

- Add student records
- Display all student records
- Search students using Linear Search
- Fast student search using HashMap
- Sort students by marks using Bubble Sort
- Delete student records
- Undo the most recent deletion using Stack
- Queue implementation for pending student requests
- Simple menu-driven console interface

## Data Structures & Algorithms

The project demonstrates the use of:

- **ArrayList** – Stores and manages student records
- **HashMap** – Provides fast student ID-based searching
- **Stack** – Implements the undo functionality
- **Queue** – Maintains pending student requests
- **LinkedList** – Used as the Queue implementation
- **Linear Search** – Searches for students sequentially
- **Bubble Sort** – Sorts students according to marks in descending order

## How to Run

1. Install **Java JDK**.
2. Open the project in a Java IDE such as **VS Code, IntelliJ IDEA, or Eclipse**.
3. Open the project folder in the IDE.
4. Compile the Java files.
5. Run `Main.java`.

### Using Terminal

```bash
javac *.java
java Main
```
